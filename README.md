# 🚦 Traffic Counter

**Traffic Counter** — це система аналізу дорожнього трафіку в реальному часі, яка працює у зв'язці Raspberry Pi (для стрімінгу відео) та комп'ютера Mac з Apple Silicon (для обробки кадру через YOLOv8 на Neural Engine).

Система автоматично підключається до камери по SSH, обробляє відеопотік, розпізнає транспортні засоби, рахує перетини контрольної лінії та визначає рівень завантаженості дороги (Free, Normal, Heavy).

---

## 🛠 Початкове налаштування (Швидкий старт)

### 1. Встановлення `uv`
Якщо у вас ще не встановлено `uv`, виконайте в терміналі (потрібен brew):
```bash
brew install uv
```

### 2. Клонування та ініціалізація
Скопіюйте репозиторій і встановіть усі залежності однією командою. `uv` автоматично створить ізольоване віртуальне середовище (`.venv`) та підтягне необхідні бібліотеки з `pyproject.toml`.
```bash
git clone <https://github.com/Den-k0/traffic_counter.git>
cd traffic-counter

# Встановлення всіх залежностей
uv sync
```

### 3. Підготовка моделі YOLOv8 (Apple Silicon)
Для максимальної швидкодії на процесорах M (через Neural Engine) нейромережу потрібно перевести у формат CoreML.

Виконайте цю команду в терміналі проєкту:
```bash
uv run yolo export model=yolov8l.pt format=coreml
```
*У результаті в папці з'явиться наша модель `yolov8l.mlpackage`*

## ⚙️ Налаштування доступу до камери (.env)

Проєкт підключається до Raspberry Pi через SSH, щоб автоматично запускати та зупиняти відеотрансляцію. 

Створіть файл `.env` у корені проєкту (використовуйте `.env.sample` як шаблон) і впишіть свої дані:

```env
# IP-адреса вашої Raspberry Pi у локальній мережі
RPI_IP=your_raspberry_pi_ip_address

# Логін SSH
RPI_USER=your_raspberry_pi_username

# Пароль від Raspberry Pi
RPI_PASS=your_raspberry_pi_password
```

## 🚀 Запуск проєкту

Після того, як модель скомпільована, а доступи вписані, просто запустіть головний файл через `uv`:

```bash
uv run main.py
```

**Що відбудеться:**
1. Проєкт підключиться до Raspberry Pi та "вб'є" старі завислі процеси камери.
2. Автоматично запустить стрім `rpicam-vid` по TCP на порт `8888`.
3. З'явиться вікно з обробленим відео, де об'єкти будуть трекатися в реальному часі.
4. При натисканні клавіші `q` або `Ctrl+C` — система коректно закриє вікно і **автоматично вимкне камеру на малині**.

## 🔧 Додатково: Лінтер та форматування (Ruff)

Проєкт підтримує лінтер/форматер `ruff`.

Щоб перевірити код і виправити дрібні помилки синтаксису:
```bash
uv run ruff check --fix .
```

Щоб автоматично відформатувати код (вирівняти відступи, лапки тощо):
```bash
uv run ruff format .
```

# 🚦 Traffic Counter

**Traffic Counter** — це розподілена система аналізу дорожнього трафіку в реальному часі. Проєкт працює у зв'язці **Raspberry Pi** (апаратний стрімінг відео) та комп'ютера **Mac з Apple Silicon** (високопродуктивний сервер обробки комп'ютерного зору та веб-дашборд).

Система автоматично підключається до камери по SSH, обробляє відеопотік через нейромережу, рахує перетини контрольної лінії та виводить детальну статистику на інтерактивний веб-дашборд через WebSockets.


## 🛠 Стек технологій та Архітектура

Проєкт побудовано за принципами **Clean Architecture (Domain-Driven Design)**, з чітким розділенням інфраструктури (камера/ML) та бізнес-логіки (API/БД).

### 🧠 Machine Learning & Computer Vision (`/camera`)
*   **YOLOv8 (Ultralytics)** — детекція та трекінг об'єктів (люди, авто, автобуси тощо).
*   **CoreML** — оптимізація моделі для виконання на Neural Engine (Apple Silicon) задля максимального FPS та енергоефективності.
*   **OpenCV** — обробка матриць зображень, рендеринг графіки (Bounding Boxes, HUD) та кодування потоку в MJPEG.
*   **Paramiko** — програмне SSH-керування Raspberry Pi (автозапуск/зупинка трансляції `rpicam-vid`).

### 🌐 Web & API (`/web`)
*   **FastAPI** — високопродуктивний асинхронний веб-фреймворк для REST API та роутингу.
*   **WebSockets** — реалізація патерну *Backend-Driven UI* для миттєвої розсилки статистики (Broadcast) на клієнти без polling-запитів.
*   **SQLAlchemy + SQLite** — ORM та легковажна база даних для збереження історії трафіку.
*   **Alembic** — система контролю версій бази даних (міграції).
*   **Pydantic Settings** — сувора типізація та валідація конфігурацій (Fail-Fast для `.env`).

### 🎨 Frontend
*   **HTML5/CSS3 + Bootstrap 5** — адаптивний UI.
*   **Chart.js** — інтерактивні графіки історичних даних.
*   **Vanilla JS** — "Тонкий клієнт" (Thin Client), який рендерить дані виключно за вказівками сервера.

## ⚙️ Початкове налаштування (Швидкий старт)

### 1. Встановлення менеджера пакетів `uv`
Проєкт використовує пакетний менеджер [uv](https://github.com/astral-sh/uv). Для його встановлення виконайте (потрібен brew):
```bash
brew install uv
```

### 2. Клонування та встановлення залежностей
Скопіюйте репозиторій. Менеджер `uv` автоматично створить ізольоване віртуальне середовище (`.venv`) та встановить усі пакети згідно з `uv.lock`.
```bash
git clone https://github.com/Den-k0/traffic_counter.git
cd traffic-counter

# Встановлення всіх залежностей
uv sync
```

### 3. Підготовка моделі YOLOv8 (Apple Silicon)
Для розблокування апаратного прискорення (Neural Engine) на процесорах Apple M-серії, необхідно конвертувати стандартну модель PyTorch у формат CoreML.

Виконайте команду:
```bash
uv run yolo export model=yolov8l.pt format=coreml nms=True
```
*(Переконайтеся, що назва згенерованого `.mlpackage` відповідає значенню `YOLO_MODEL` у `config.py`)*

### 4. Налаштування доступу до камери (`.env`)
Проєкт підключається до камери Raspberry Pi через SSH. Створіть файл `.env` у корені проєкту (з `.env.sample`) та впишіть актуальні дані доступу:
```env
# IP-адреса Raspberry Pi у локальній мережі
RPI_IP=192.168.0.100

# SSH облікові дані
RPI_USER=pi
RPI_PASS=raspberry
```

### 5. Ініціалізація бази даних
Система використовує SQLite для зберігання історії. Перед першим запуском створіть таблиці за допомогою системи міграцій Alembic:
```bash
uv run alembic upgrade head
```


## 🚀 Запуск системи

Після налаштування середовища та бази даних, запустіть головний файл застосунку:
```bash
uv run main.py
```

**Життєвий цикл роботи системи:**
1. **Ініціалізація:** FastAPI піднімає веб-сервер на порту `8000`.
2. **Фонові процеси (Threads):** Запускається воркер запису в базу даних та конвеєр комп'ютерного зору (YOLO).
3. **Стрімінг:** `SSHCameraController` автоматично підключається до Raspberry Pi, "вбиває" завислі процеси камери та піднімає новий TCP-стрім.
4. **Дашборд:** Відкрийте браузер за адресою [http://localhost:8000](http://localhost:8000).
5. **Smart Rendering:** *Оптимізація ресурсів* — якщо ви закриєте вкладку браузера, бекенд припинить кодування кадрів у JPEG, зберігаючи ресурси CPU, але YOLO продовжить аналізувати трафік у фоні.
